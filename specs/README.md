# Format references

One doc per format. Each cites the authoritative source (URL) and gives our own
distilled notes plus a pointer to the C reference parser.

IMPORTANT: cite specs, do not paste copyrighted spec text verbatim (W3C WebVTT,
Microsoft SAMI, Apple QTtext). For the de-facto formats (SRT, MicroDVD, MPL2,
SubViewer, TMPlayer, MPSub, LRC, DKS) there is no authoritative spec. The C
`subparse` implementation is the reference, so describe its behavior.
